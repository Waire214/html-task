HTML TABLE ELEMENTS

Define all text formatting tags of HTML in a table

Below is a list of all HTML text formatting tags

Tag Description
<b> Bold text
<i> Italic text
<u> Underlined text
<mark> Highlighted text
<small> Small text
<del> Deleted text
<ins> Inserted text
<sub> Subscript text
<sup> Superscript text
<code> Code text
<kbd> Keyboard input text
<var> Variable text
<cite> Citation text
<q> Quoted text
<abbr> Abbreviated text
<time> Time text
<address> Address text
<bdo> Bi-directional override text
<bdi> Bi-directional isolation text
<span> Generic inline container
<strong> Strong importance text
<em> Emphasized text
<dfn> Definition text
<s> Strikethrough text (for stylistic purposes)
<pre> Preformatted text (preserves spaces and line breaks)
<samp> Sample output from a program or computer system
<ruby> Defines ruby annotation (pronunciation guide)
<rt> Ruby text — used inside <ruby> to define pronunciation
<rp> Fallback parentheses for ruby text if not supported
<br> Line break (inserts a new line)
<wbr> Word break opportunity (hints where to break long words)
